샘플: 새 문서가 사이트에 오르기까지

원본 하나가 공통 틀에 감싸여 사이트 HTML 이 되기까지를 따라간다.

1원본에서 사이트까지의 흐름

  1. 공통 틀로 감싸기
    • build.py가 원본 본문을 templates/partials/layout.html에 넣음
    • 장 번호 · 목차 · 이전/다음 링크를 자동으로 붙임
  2. 규칙 검사
    • STYLE.md 의 [자동] 규칙을 결과 HTML 에서 검사
    • 위반하면 파일:줄과 이유를 보여 주고 멈춤
  3. 사이트 HTML
    • <주제>/<문서>.html로 저장

2원본에 쓰는 것과 틀이 하는 것

원본 (src)공통 틀 · 빌드
머리말
  • title · description · lead
  • head · 문서 제목 · 첫 문장에 채움
장
  • <section class="chapter"> + h2
  • id · 번호 · 목차
순서
  • series.json 의 pages
  • 목록 번호 · 이전/다음 링크

그림 이름과 목차 문구

항목내용
그림 이름
  • 사이트 전체에서 하나의 이름 공간
  • "<주제>-" 접두어를 붙임
목차 문구
  • 기본은 h2 그대로
  • 짧게 하려면 data-toc
  • 결과 HTML 은 직접 고치지 않는다. 다음 빌드에서 덮어써진다

3코드와 설정

cp templates/page.html src/kafka/new-doc.html
python3 tools/build.py
파일기본값설명
series.json hiddenfalse
  • true 면 홈 목록에 안 나옴
  • 샘플 · 작성 중 주제에 씀

    • 머리말 + 장만 쓴다
  • 빌드
    • 틀로 감싸고 번호 · 목차 · 링크를 붙인 뒤 규칙을 검사한다
